# Professional Skills Development Program

## Overview
This project is a **12-week curriculum platform** designed to help participants build professional skills while providing nonprofits with measurable proof of service. The program combines **learning modules, video documentation, surveys, and assignment submissions** into one unified system.

At the end of the program, each participant will have:
- A completed **resume**
- A tailored **cover letter**
- A **90-day job search plan**
- A strengthened **professional mindset**

Nonprofit staff will have access to:
- **Dashboards** showing participant progress
- **Tables and reports** with names, dates, assignments, and emails
- **Proof of participation** through video and assignment submissions

---

## Features
- **Participant Portal**
  - Sign-in page (email + password)
  - Video lessons
  - Surveys and personality tests
  - Assignment uploads (resume drafts, cover letters, reports)
  - Progress tracker

- **Organization Dashboard**
  - Tables of participant submissions
  - Exportable reports (CSV/PDF)
  - Proof of service logs
  - Impact metrics (attendance, completion rates)

---

## Tech Stack
- **Frontend**: HTML, CSS, JavaScript (templates with Jinja2)
- **Backend**: Python (Flask/Django)
- **Database**: PostgreSQL/MySQL (for participant data)
- **Storage**: Cloud (AWS S3, Google Cloud, or Azure for videos/files)
- **Integration**: Google Sheets API or Microsoft Graph for reporting
